**Linux Luminarium Notes**



**Commands:**

**cat**: print content of a file

**grep**: *search* inside a file (useful to remember)

**diff:** Difference between files. Kinda in the name.

**rm:** remove file (or add -r to do directories) 

**rmdir:** remove EMPTY directory

**ls -a:** Lists hidden files too

**find:** if you specify a folder, it'll give you all the stuff in the folder, -name is all of that name under where you're searching

**ln -s TARGET LINK\_NAME:** This create a soft symlink for TARGET with the LINK\_NAME and cat LINK\_NAME will print that.





**Types of files:**

&#x20;- is a regular file

d is a directory

l is a symbolic link.. which is essentially a path to another file (created using ln)
